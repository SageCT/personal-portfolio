# sagect-portfolio

The Next.js app behind my personal portfolio.

**Full documentation lives in the [root README](../README.md):** stack, project
structure, routes, and how the site is put together.

## Quick start

Requires [Bun](https://bun.sh) 1.4+.

```bash
bun install
```

```bash
bun run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

| Script | What it does |
| --- | --- |
| `bun run dev` | Start the dev server on port 3000 |
| `bun run build` | Production build |
| `bun run start` | Serve the production build |
| `bun run lint` | Lint and format check with Biome |
| `bun run format` | Rewrite files with Biome's formatter |
